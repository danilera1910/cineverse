# 🎬 Cineverse

Um catálogo de filmes desenvolvido como projeto de estudo para praticar desenvolvimento web.

## 🚀 Sobre o projeto

O Cineverse é um site de filmes desenvolvido com **HTML, CSS e JavaScript**.

A proposta é criar uma experiência de catálogo onde o usuário pode explorar filmes, pesquisar títulos, filtrar por gênero e visualizar informações sobre cada filme.

## ✨ Funcionalidades

* 🎬 Catálogo de filmes
* 🔎 Pesquisa por título
* 🎭 Filtro por gênero
* ⭐ Avaliação dos filmes
* 📖 Informações e descrição dos filmes
* 🎞️ Filmes semelhantes
* 📱 Layout responsivo
* 🖥️ Interface inspirada em plataformas de streaming

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📚 Objetivo

Este projeto faz parte do meu processo de aprendizado em desenvolvimento web e tem como objetivo praticar conceitos de **HTML, CSS e JavaScript**, além de desenvolver projetos para meu portfólio e GitHub.
